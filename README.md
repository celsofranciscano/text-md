# Text MD

**Text MD** es una aplicación web local para crear, organizar y editar documentos Markdown mediante proyectos.

## Características

- Organización de documentos por proyectos.
- Editor Markdown.
- Vista previa en tiempo real.
- Modos edición, vista previa y dividido.
- Creación, edición, duplicación y eliminación de documentos.
- Búsqueda de documentos.
- Importación y exportación de archivos `.md`.
- Autoguardado.
- Persistencia mediante `localStorage`.
- Tema claro y oscuro.
- Diseño responsive inspirado en Notion.

## Tecnologías

- HTML5
- JavaScript
- Tailwind CSS
- Marked.js
- DOMPurify
- Lucide Icons
- LocalStorage

## Uso

Clona el repositorio:

```bash
git clone <URL_DEL_REPOSITORIO>
cd text-md
```
